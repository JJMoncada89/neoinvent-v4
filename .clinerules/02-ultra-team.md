# 🏆 ULTRA_TEAM — Protocolo obligatorio (activado 2026-08-29)

Toda tarea de desarrollo en este proyecto se ejecuta bajo el sistema ULTRA_TEAM:

1. Lee el protocolo completo: `/home/exodus/PROYECTOS/ULTRA_TEAM/PROTOCOLO.md`
2. Activa las skills de `.cline/skills/` según el dominio de la tarea
   (mapa skill↔rol↔gate en `/home/exodus/PROYECTOS/ULTRA_TEAM/SKILLS.md`).
3. Cadena mínima: `plan-decompose` → `docs-first` → build (G1 tras cada edición)
   → gates del dominio (G2/G3/G4) → `diff-audit` → `ship-deploy` → `session-closeout`.
4. Nada está terminado sin evidencia de verificación real (navegador para UI,
   ejecución para backend, cruces para datos).

Nota: este proyecto conserva además sus reglas core propias (01-core-lessons.md)
y su skill `browser-validate` local, que prevalecen sobre la versión general.
